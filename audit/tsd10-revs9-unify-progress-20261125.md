# TSD10 RevS9 공통형상 통합 검증 현황 (2026-11-25, KST)

## 사용자 확정 요구
- **상부/하부 배터리형 모두 유지**. XT60/XT90까지 4개 구성을 유지한다.
- 공통 프레임 및 안테나 브래킷의 실제 형상은 상부형을 기준으로 통일한다. **목록 통합과 형상 통일은 서로 다르다.**
- 후방 붉은 표시 범위 연장과 전체 홀/결합/간섭 검사 없이 제조 승인 금지.
- 원본 Rev W 및 RevS8 CAD 메시 자산 변경 금지. 별도 검토 리비전에서만 변경.

## 완료된 소스 변경 및 근거
- GitHub main: `tsd10-preview.html`을 RevS8 4조합 CAD 조립 뷰어로 전환. 기존 Rev W는 `archive/tsd10-preview-revw-20261125.html`에 보존. 커밋 `02b6f70fa4e8e8a9cf4d9b2bf0b3821948309ac0`.
- GitHub main: `index.html`에 'TSD10 3D 검토' 진입 링크 추가. 기존 `drone-design.html`은 보존. 커밋 `0255dd11d0fb477f5bec078452bca50d8efd5082`.
- 리뷰 소스: 안테나 RF 브래킷의 상하 공통 **BOM 표시명**을 `후방 RF 안테나 브래킷 · 공통 목록 (형상 검증 중)`으로 통합. 원본 3D 메시·부품 ID `p6` 보존.
- 뷰어에는 상판/하판 포함·오분류 검사를 추가해 카테고리 오류를 숨기지 않음.
- 네 조합의 프레임 카테고리 부품 10개/조합, 상판 1·하판 1, RF 브래킷 p6 1개/조합 확인.
- GPS 카테고리 부품은 장착판, 참조 본체, 0.5mm 안착 심 **3개/조합**. 본체/장착판의 경계상자 중심 간격 **5.204mm**. 이는 체결면 실제 갭 또는 장착 승인값이 아님.

## 다음 단계 및 차단 조건
1. 실제 RevZ1/RevS8 STEP B-Rep의 획득 가능 여부 확인. 현재 이 GitHub 저장소의 main 및 리뷰 브랜치 트리에는 `.step`/`.stp`가 없고 Base64 압축 3D 표시용 메시만 있음.
2. 사용자가 그린 붉은 표시 영역의 정확한 경계를 원본 이미지·치수와 연결. 추정 연장 금지.
3. 상부형 기준 하판·좌/우 C형 보호판·RF 브래킷 4부품을 설계 원본에서 수정하고 배터리/전원/FC/GPS/안테나 체결 및 간섭 확인.
4. 4개 조립 조합 및 관련 부품 전체의 STEP/STL/GLB 추출·재검증. 파일 버전 보존.
5. 동일 Rev 자산으로 공개 `drone-design.html`과 `tsd10-preview.html`을 정합화. 현재 공개 `drone-design.html`은 기존 모델로 유지되어 미완료.
6. 실제 제조 승인 판정은 수행하지 않음(`manufacturingApproved=false`). 99% 완료 판정 금지.
